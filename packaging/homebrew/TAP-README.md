# homebrew-tabcap

Homebrew tap for [tabcap](https://github.com/1A7432/tabcap), a browser for AI agents.

```sh
brew install 1A7432/tabcap/tabcap
tabcap setup          # downloads Chrome for Testing once
brew upgrade tabcap   # later
```

macOS arm64 and Linux (x64, arm64). `Formula/tabcap.rb` is pushed here by the tabcap repository's `homebrew.yml` workflow for every published release; its template is `packaging/homebrew/tabcap.rb` there.
